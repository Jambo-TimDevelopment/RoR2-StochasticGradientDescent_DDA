## Обзор алгоритма SGD DDA

Этот мод добавляет к артефакту «Genetics» альтернативный режим динамической адаптации сложности (DDA), основанный на **стохастическом градиентном спуске (SGD)**.

- **Цель**: автоматически подстраивать сложность монстров под текущий уровень игры игрока так, чтобы сохранялся комфортный, но напряжённый геймплей.
- **Отличие от генетического алгоритма**: вместо эволюции популяции генов по поколениям SGD DDA непрерывно корректирует параметры сложности во времени, как онлайн‑обучение.

Подробнее об общей архитектуре мода и правилах интеграции см. основной файл проекта [`RULE.md`](../../RULE.md).

## Высокоуровневая схема

На логическом уровне алгоритм организован как конвейер:

1. **Sensors (сенсоры)** собирают телеметрию игрока.
2. **Decision (решение, SGD)** оценивает, насколько текущая сложность соответствует уровню игры, и делает шаги градиентного спуска.
3. **Actuators (актуаторы)** применяют новые множители характеристик монстров.

Входы и выходы:

- **Вход**: телеметрия игрока (точность стрельбы, входящий/исходящий урон, смерти, время до убийства монстров и др.).
- **Выход**: множители `GeneStat` для монстров:
  - `MaxHealth`
  - `MoveSpeed`
  - `AttackSpeed`
  - `AttackDamage`
- **Механизм**: каждая ось сложности имеет свой параметр \\( \\theta \\) и собственный SGD‑процесс, стремящийся к состоянию `skill ≈ challenge`.
